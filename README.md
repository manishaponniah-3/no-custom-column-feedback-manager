# AI Feedback Manager

A Linear-style feedback management system for tracking and organizing AI agent feedback.

## Live Demo

Visit: https://manishaponniah-3.github.io/ai-feedback-manager

## Features

- **Status Management**: Track feedback through different states (Created, In Progress, Testing, Verifying, Closed)
- **Custom Columns**: Add up to 10 custom columns with different types (text, number, date, select, person, checkbox)
- **Auto-increment Counters**: Number columns can auto-increment sequentially
- **Commenting System**: Add comments and replies to feedback items
- **Filtering & Search**: Filter by status, agent, date range, or search by keyword
- **Pagination**: Browse through lists with 50 items per page
- **Sortable Columns**: Sort by status or created date

## Usage

This is a frontend mockup with no backend. All interactions are client-side only.

## Local Development

Simply open `index.html` in any web browser - no server or dependencies required!
